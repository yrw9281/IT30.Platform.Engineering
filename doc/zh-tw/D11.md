# Day 11 - 終結供應商鎖定：OpenTelemetry (OTel) 統一標準與架構全解

## 前言

OpenTelemetry（OTel）定義遙測資料的 API、SDK、語意慣例與傳輸協定，不是單一的監控產品。它讓應用程式的 instrumentation 可以與不同後端解耦。

## 為何中間需要 Collector

SDK 負責在應用程式產生 spans、metrics 與 logs；Collector 集中處理重試、批次、敏感欄位移除與後端路由。應用程式不應知道每一個 observability backend 的連線細節。

## 結語
