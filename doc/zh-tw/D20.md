# Day 20 - K8s 內的翻譯官：介紹 Operator 模式與輕量級框架 Kopf

## 前言

Operator 是把領域操作知識編碼成控制器的模式。對這個教學平台，Python 的 Kopf 可讓我們專注於 handler 與狀態收斂，不必先處理完整 Go controller 樣板。

## Handler 的責任輪廓

```python
@kopf.on.create("platform.example.io", "v1alpha1", "microservices")
def create_microservice(spec, name, namespace, **_):
    desired = render_deployment(spec, name)
    apply_desired_resources(desired, namespace)
    return {"phase": "Progressing"}
```

這是規劃片段：實作時 handler 必須具備 idempotency，重複事件不能造成重複資源；更新與刪除事件也要明確設計。

## Operator 不該做的事

Operator 不應把業務邏輯、密鑰或環境專屬值寫死在程式中。它應從 CR 讀取意圖、套用平台預設、觀察子資源，最後更新 CR status。
