## 由 CR 產生的 Deployment 片段

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: catalog-api
  labels:
    platform.example.io/managed-by: microservice-operator
spec:
  template:
    spec:
      containers:
        - name: app
          image: registry.example.internal/catalog-api@sha256:******
          ports:
            - name: http
              containerPort: 8080
          env:
            - name: OTEL_SERVICE_NAME
              value: catalog-api
```

## 將子資源狀態回寫

```yaml
status:
  observedGeneration: 3
  phase: Healthy
  deployment: catalog-api
  service: catalog-api
```

`Healthy` 不該在資源建立後立刻寫入，而要依 Deployment available condition 等實際狀態收斂。這個 status 也會成為 Argo CD health check 的依據。
