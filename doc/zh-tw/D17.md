# Day 17 - CI 與 GitOps 的交響樂：職責分離與自動化銜接機制

## 前言

CI 證明某個 image 可以交付；CD 決定何時、往哪個環境交付。分離職責後，CI 寫入 GitOps repository 的 image reference，Argo CD 才依 Git 的 merge 結果同步。

## 只更新宣告中的版本

```yaml
# apps/catalog-api/overlays/staging/kustomization.yaml
images:
  - name: registry.example.internal/catalog-api
    newName: registry.example.internal/catalog-api
    digest: sha256:******
```

## 交接流程

```text
CI test/build/scan -> create config branch -> update image digest
-> pull request/review -> merge -> Argo CD sync
```

CI 對 config repository 使用專屬、最小權限的 token；自動更新也必須走 branch protection。這使每次生產部署都有原始碼 commit、image digest 與 config commit 的關聯。
